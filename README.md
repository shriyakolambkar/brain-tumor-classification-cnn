# brain-tumor-classification-cnn

## Dataset

The MRI images used in this project were obtained from the following Kaggle dataset:

- [Brain Tumor Classification (MRI) – Sartaj Bhuvaji](https://www.kaggle.com/datasets/sartajbhuvaji/brain-tumor-classification-mri/data)

The dataset contains four categories:
- Glioma Tumor
- Meningioma Tumor
- No Tumor
- Pituitary Tumor
